# Лабораторная работа №7: Интеграция БД, Сети и Dependency Injection

## Описание
В данной лабораторной работе произведено объединение двух предыдущих проектов: приложения для расчёта вкладов (с локальной БД Room) и клиента для работы с REST API (с JWT-авторизацией). 
Ключевая цель работы - построение чистой MVVM-архитектуры с использованием механизма внедрения зависимостей (Dependency Injection) и изоляция пользовательских данных.

## Что было сделано:

1. **Внедрение зависимостей (DI) через Koin:**
   - Приложение полностью переведено на Koin (выбран как оптимальный DI-фреймворк для Kotlin/Compose).
   - Создан `AppModule`, который управляет созданием синглтонов (`AppDatabase`, `DepositDao`, репозитории) и инжектит их прямо в конструкторы `ViewModel`. Из кода убрано ручное создание зависимостей.

2. **Изоляция локальных данных (Room):**
   - Обновлена сущность `DepositEntity`: добавлено поле `userLogin` для привязки расчетов к конкретному пользователю.
   - Обновлен DAO и репозиторий: теперь история запрашивается строго для текущего авторизованного пользователя. Применена стратегия деструктивной миграции БД для обновления схемы.

3. **Сложная навигация (Jetpack Compose Navigation):**
   - **Глобальная навигация:** Умный старт приложения. Если в `SharedPreferences` (через `TokenManager`) есть токен — сразу открывается главный экран, иначе - экран входа.
   - **Локальная навигация:** Реализовано нижнее меню (`BottomNavigationView`) с тремя независимыми вкладками:
     * *Пользователи* (данные подтягиваются с сервера через Retrofit).
     * *Новый расчёт* (калькулятор с сохранением результата в Room).
     * *Мои расчёты* (динамическая история сохраненных вкладов текущего юзера).

4. **Управление сессией и исправление багов:**
   - Доработан `TokenManager`: теперь он сохраняет не только JWT-токен, но и логин пользователя при входе/регистрации, что позволило надежно разделять историю расчетов между разными аккаунтами на одном устройстве.

## Стек технологий
* **Язык:** Kotlin
* **UI:** Jetpack Compose, Material Design 3
* **Архитектура:** MVVM, StateFlow, Coroutines
* **DI (Внедрение зависимостей):** Koin
* **Локальная БД:** Room (SQLite)
* **Сеть:** Retrofit 2, OkHttp, kotlinx.serialization
* **Хранилище сессии:** SharedPreferences
