# Лабораторная работа №6: Интеграция с API и аутентификация

## Описание
В этой лабораторной работе реализовано клиент-серверное взаимодействие для Android-приложения. Приложение умеет регистрировать новых пользователей, авторизовываться (с использованием JWT-токенов) и получать защищенные данные с локального сервера.

## Что было сделано:

1. **Настроена работа с сетью (Retrofit + OkHttp):** - Настроен клиент для запросов к локальному бэкенду (использован алиас `10.0.2.2` для работы через эмулятор).
   - Подключена библиотека `kotlinx.serialization` для парсинга JSON.

2. **Реализована JWT-авторизация:**
   - Создан `AuthInterceptor`, который автоматически прикрепляет токен в заголовок `Authorization` ко всем исходящим запросам.
   - Написан `TokenManager` для безопасного хранения токена в `SharedPreferences` (пользователь остается в системе после перезапуска приложения).

3. **Архитектура MVVM:** - Сетевая логика вынесена в `AuthRepository`.
   - Управление состояниями (загрузка, ошибки, данные) реализовано через `AuthViewModel` и `StateFlow`.

4. **Интерфейс на Jetpack Compose:**
   - Сверстаны экраны входа, регистрации и списка пользователей по стандартам Material 3.
   - Улучшен UX регистрации: написана маска для ввода телефона `+7(XXX)-XXX-XX-XX`, добавлен системный календарь для выбора даты рождения (с ограничением ввода будущих дат) и выпадающие списки (список групп динамически подтягивается с сервера).

5. **Работа с бэкендом (Docker):** - Выданный Spring Boot бэкенд успешно развернут локально через `docker-compose`. 
   - Самостоятельно исправлены ошибки в конфигурации сборки бэкенда (настроен правильный билд `bootWar` в Gradle) и устранен рассинхрон URL-путей между клиентом и сервером.

## Стек технологий
* **Язык:** Kotlin
* **UI:** Jetpack Compose, Material 3
* **Архитектура:** MVVM, Coroutines, StateFlow
* **Сеть:** Retrofit, OkHttp
* **Локальное хранилище:** SharedPreferences
